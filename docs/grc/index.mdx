# Język starogrecki

## Klasyfikacja genetyczna i strukturalna

Rodzina indoeuropejska, samodzielna grupa grecka. Język fleksyjny — pięć przypadków, trzy rodzaje, trzy liczby (w tym podwójna), bogaty system aspektowo-czasowy.

## Liczba użytkowników i rozmieszczenie geograficzne

Język historyczny — wymarły. Używany w nauce klasycznej i tradycji liturgicznej Kościoła prawosławnego (w odmianie koine).
Współcześnie potomkiem jest [nowogrecki](/ell).

## Dialekty

Cztery główne dialekty antyczne: jońsko-attycki (Attyka, kolonie jońskie), dorycki (Peloponez, Kreta, Sycylia), eolski (Lesbos, Beocja, Tesalia), arkado-cypryjski.
Hellenistyczna *koine* (od IV w. p.n.e.) — oparta na attyckim.

## Fonetyka

Samogłoski długie i krótkie (pięć par).
Akcent muzyczny (tonalny) — ostry, ciężki, perispomenon.
System aspiracji: *psili* (gładkie) i *dasia* (przydech).

## System pisma

Alfabet grecki (24 litery, od ok. VIII w. p.n.e.) — adaptacja pisma fenickiego.
Pisownia z diakrytykami: akcenty, przydechy, *iota subscriptum*.
Wcześniej linearne B (mykeńskie, ok. 1450-1200 p.n.e.).

## Historia

Mykeński (XV-XII w. p.n.e.), wieki ciemne, epoka archaiczna (Homer, VIII w. p.n.e.), klasyczna (V-IV w. p.n.e. — Platon, Tukidydes), hellenistyczna (*koine* — Septuaginta, Nowy Testament), bizantyjska.
Podstawa terminologii naukowej Europy.
