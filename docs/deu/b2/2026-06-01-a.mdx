# Lekcja 1: Uporządkowane argumenty

```lesson-vocabulary lang=deu script=latn
die Meinung {N f sg} [dee MAI-noong] = opinia
der Grund {N m sg} [dehr groont] = powód
hilfreich {Adj} [HILF-raikh] = pomocny
allerdings {Adv} [AH-ler-dings] = jednak
beachten {V} [be-AKH-ten] = brać pod uwagę
die Kosten {N pl} [dee KOS-ten] = koszty
```

```lesson-models lang=deu script=latn
Ich bin der Meinung, dass X [ikh bin dehr MAI-noong das X] = jestem zdania, że X
Ein wichtiger Grund ist X [ain VIKH-ti-ger groont ist X] = ważnym powodem jest X
Allerdings sollte man auch X beachten [AH-ler-dings ZOL-te man aukh X be-AKH-ten] = jednak trzeba też wziąć X pod uwagę
```

```lesson-text lang=deu script=latn
**Ein kurzer Standpunkt**

Ich bin der Meinung, dass ein klarer Lernplan hilfreich ist. Er zeigt, was man heute lernen soll.

Ein wichtiger Grund ist die Motivation. Kleine Aufgaben machen den Fortschritt sichtbar.

Allerdings sollte man auch die Zeit beachten. Ein Plan muss realistisch sein, sonst verliert man schnell die Lust.
```

```lesson-transcription lang=deu script=latn system="simple pronunciation"
Ich bin der Meinung, dass ein klarer Lernplan hilfreich ist.

Ein wichtiger Grund ist die Motivation.

Allerdings sollte man auch die Zeit beachten.
```

```lesson-translation lang=pol script=latn
**Krótki punkt widzenia**

Jestem zdania, że jasny plan nauki jest pomocny. Pokazuje, czego należy nauczyć się dzisiaj.

Ważnym powodem jest motywacja. Małe zadania sprawiają, że postęp jest widoczny.

Jednak trzeba też wziąć pod uwagę czas. Plan musi być realistyczny, inaczej szybko traci się chęć.
```

```lesson-exercise lang=deu script=latn
Połącz elementy w niemieckie zdania.

1.  Ich bin der Meinung, dass _________.
2.  Ein wichtiger Grund ist _________.
3.  Allerdings sollte man auch _________ beachten.
```

```lesson-exercise lang=deu script=latn
Napisz argument o nauce, pracy albo podróży.

1.  Podaj tezę.
2.  Dodaj jeden powód.
3.  Dodaj jedno ograniczenie.
```
