```models lang=lat script=latn
Marcus = Marek
in scholam = do szkoły
properat = śpieszy
Marcus in scholam properat. = Marek śpieszy do szkoły.

puer Romanus = chłopiec rzymski
Marcus puer Romanus est. = Marek jest chłopcem rzymskim.
multi pueri = liczni chłopcy
Multi pueri adproperant. = Liczni chłopcy nadbiegają.

vestimentum pueri = ubranie chłopca
toga = toga
Vestimentum pueri Romani toga est. = Ubraniem chłopca rzymskiego jest toga.
tunicae puerorum = tuniki chłopców
Etiam tunicae puerorum Romanorum vestimenta sunt. = Także tuniki chłopców rzymskich są ubraniami.

servi = niewolnicy
tabulas portant = noszą tabliczki
Servi pueris tabulas portant. = Niewolnicy noszą chłopcom tabliczki.
fortuna servorum = los niewolników
Fortuna servorum misera est. = Los niewolników jest nieszczęsny.

fidi servi = wierni niewolnicy
viris liberis = wolnym mężom
cari sunt = są drodzy
Sed fidi servi viris liberis cari sunt. = Lecz wierni niewolnicy są drodzy wolnym mężom.
```
