# PhraseForge

Wybierz język, aby przejrzeć dostępne poziomy CEFR i lekcje.

## Dostępne języki

- [Hiszpański (`spa`)](./spa)
- [Niemiecki (`deu`)](./deu)
- [Arabski (`arb`)](./arb)

## Struktura katalogów

Lekcje są uporządkowane według języka i poziomu:

```text
docs/{iso-639-3-code}/{cefr-level}/{lesson-slug}.mdx
```

Używaj trzyliterowych kodów ISO języków, takich jak `arb`, `pol`, `deu` lub
`spa`. Poziom musi być jednym z: `a1`, `a2`, `b1`, `b2`, `c1` albo `c2`.
