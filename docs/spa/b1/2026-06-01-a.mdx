# Lekcja 1: Codzienne opinie

```lesson-vocabulary lang=spa script=latn
creo que {V} [KRE-o ke] = myślę, że
la opinión {N f sg} [la o-pi-NYON] = opinia
buena opción {N f sg} [BWE-na op-SYON] = dobra opcja
porque {Conj} [POR-ke] = ponieważ
fácil de usar {Adj} [FA-sil de u-SAR] = łatwy w użyciu
¿Qué piensas? {Question} [ke PYEN-sas] = co myślisz?
```

```lesson-models lang=spa script=latn
Creo que X es una buena opción [KRE-o ke X es U-na BWE-na op-SYON] = myślę, że X to dobra opcja
Me gusta porque X [me GUS-ta POR-ke X] = podoba mi się, ponieważ X
¿Qué piensas de X? [ke PYEN-sas de X] = co myślisz o X?
```

```lesson-text lang=spa script=latn
**Una opinión sencilla**

Creo que estudiar por la mañana es una buena opción. Tengo más energía y recuerdo mejor las palabras.

Me gusta este plan porque es fácil de seguir. Solo necesito diez minutos y una lista corta.

¿Qué piensas de este plan? Podemos cambiar la hora si prefieres estudiar por la tarde.
```

```lesson-transcription lang=spa script=latn system="simple pronunciation"
Creo que estudiar por la mañana es una buena opción.

Me gusta este plan porque es fácil de seguir.

¿Qué piensas de este plan?
```

```lesson-translation lang=pol script=latn
**Prosta opinia**

Myślę, że nauka rano to dobra opcja. Mam więcej energii i lepiej pamiętam słowa.

Podoba mi się ten plan, ponieważ łatwo za nim podążać. Potrzebuję tylko dziesięciu minut i krótkiej listy.

Co myślisz o tym planie? Możemy zmienić godzinę, jeśli wolisz uczyć się po południu.
```

```lesson-exercise lang=spa script=latn
Uzupełnij zdania po hiszpańsku.

1.  Creo que _________ es una buena opción.
2.  Me gusta porque _________.
3.  ¿Qué piensas de _________?
```

```lesson-exercise lang=spa script=latn
Napisz dwie krótkie opinie.

1.  Jedna opinia ma być pozytywna.
2.  Druga opinia ma zawierać prostą zmianę planu.
```
