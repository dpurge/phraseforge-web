# Modern Greek language

## Genetic and structural classification

Indo-European family, independent Hellenic branch. The direct descendant of Byzantine Greek and Koine. An inflected language with four cases.

## Number of users and geographic distribution

About 13.5 million speakers. Greece, Cyprus, minorities in Albania, Italy, Turkey, and the diaspora (USA, Australia).

## Dialects

The literary standard is *Dimotiki* (δημοτική). Other varieties: Cypriot, Cretan, Pontic, Tsakonian (the only living descendant of the Doric dialect), Calabrian and Salentine Greek (Greko/Griko).

## Phonetics

Five-vowel system (a, e, i, o, u), without length distinction. Fricative consonants *θ, ð, x, ɣ*. Dynamic, mobile stress.

## Writing system

Greek alphabet (24 letters) — the same set as Ancient Greek, but reading and spelling have been modernized. Since 1982, only a single accent (*monotoniko*) is used.

## History

Descended from Koine — the common Greek of the Hellenistic era. Medieval (Byzantine) Greek → Modern Greek. The 19th-20th centuries saw the conflict between Dimotiki and *Katharevousa* (an artificial archaizing form); in 1976 Dimotiki became the official language.
