# Lesson 1: Everyday Opinions

```lesson-vocabulary lang=spa script=latn
creo que {V} [KRE-o ke] = I think that
la opinión {N f sg} [la o-pi-NYON] = opinion
buena opción {N f sg} [BWE-na op-SYON] = good option
porque {Conj} [POR-ke] = because
fácil de usar {Adj} [FA-sil de u-SAR] = easy to use
¿Qué piensas? {Question} [ke PYEN-sas] = what do you think?
```

```lesson-models lang=spa script=latn
Creo que X es una buena opción [KRE-o ke X es U-na BWE-na op-SYON] = I think X is a good option
Me gusta porque X [me GUS-ta POR-ke X] = I like it because X
¿Qué piensas de X? [ke PYEN-sas de X] = What do you think about X?
```

```lesson-text lang=spa script=latn
**Una opinión sencilla**

Creo que estudiar por la mañana es una buena opción. Tengo más energía y recuerdo mejor las palabras.

Me gusta este plan porque es fácil de seguir. Solo necesito diez minutos y una lista corta.

¿Qué piensas de este plan? Podemos cambiar la hora si prefieres estudiar por la tarde.
```

```lesson-transcription lang=spa script=latn system="simple pronunciation"
Creo que estudiar por la mañana es una buena opción.

Me gusta este plan porque es fácil de seguir.

¿Qué piensas de este plan?
```

```lesson-translation lang=eng script=latn
**A Simple Opinion**

I think studying in the morning is a good option. I have more energy and remember words better.

I like this plan because it is easy to follow. I only need ten minutes and a short list.

What do you think about this plan? We can change the time if you prefer to study in the afternoon.
```

```lesson-exercise lang=spa script=latn
Complete the Spanish sentences.

1.  Creo que _________ es una buena opción.
2.  Me gusta porque _________.
3.  ¿Qué piensas de _________?
```

```lesson-exercise lang=spa script=latn
Write two short opinions.

1.  One opinion should be positive.
2.  The other should include a simple change of plan.
```
