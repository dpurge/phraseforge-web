# PhraseForge

Choose a language to browse available CEFR levels and lessons.

## Available languages

- [Spanish (`spa`)](./spa)
- [German (`deu`)](./deu)
- [Arabic (`arb`)](./arb)

## Directory pattern

Lessons are organized by language and level:

```text
docs/{iso-639-3-code}/{cefr-level}/{lesson-slug}.mdx
```

Use three-letter ISO language codes such as `arb`, `pol`, `deu`, or `spa`.
Levels must be one of `a1`, `a2`, `b1`, `b2`, `c1`, or `c2`.
