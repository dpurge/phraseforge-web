# Lesson 1: Structured Arguments

```lesson-vocabulary lang=deu script=latn
die Meinung {N f sg} [dee MAI-noong] = opinion
der Grund {N m sg} [dehr groont] = reason
hilfreich {Adj} [HILF-raikh] = helpful
allerdings {Adv} [AH-ler-dings] = however
beachten {V} [be-AKH-ten] = to take into account
die Kosten {N pl} [dee KOS-ten] = costs
```

```lesson-models lang=deu script=latn
Ich bin der Meinung, dass X [ikh bin dehr MAI-noong das X] = I am of the opinion that X
Ein wichtiger Grund ist X [ain VIKH-ti-ger groont ist X] = an important reason is X
Allerdings sollte man auch X beachten [AH-ler-dings ZOL-te man aukh X be-AKH-ten] = however, one should also take X into account
```

```lesson-text lang=deu script=latn
**Ein kurzer Standpunkt**

Ich bin der Meinung, dass ein klarer Lernplan hilfreich ist. Er zeigt, was man heute lernen soll.

Ein wichtiger Grund ist die Motivation. Kleine Aufgaben machen den Fortschritt sichtbar.

Allerdings sollte man auch die Zeit beachten. Ein Plan muss realistisch sein, sonst verliert man schnell die Lust.
```

```lesson-transcription lang=deu script=latn system="simple pronunciation"
Ich bin der Meinung, dass ein klarer Lernplan hilfreich ist.

Ein wichtiger Grund ist die Motivation.

Allerdings sollte man auch die Zeit beachten.
```

```lesson-translation lang=eng script=latn
**A Short Point of View**

I am of the opinion that a clear study plan is helpful. It shows what one should learn today.

An important reason is motivation. Small tasks make progress visible.

However, one should also take time into account. A plan must be realistic, otherwise motivation disappears quickly.
```

```lesson-exercise lang=deu script=latn
Combine the elements into German sentences.

1.  Ich bin der Meinung, dass _________.
2.  Ein wichtiger Grund ist _________.
3.  Allerdings sollte man auch _________ beachten.
```

```lesson-exercise lang=deu script=latn
Write an argument about studying, work, or travel.

1.  Give one claim.
2.  Add one reason.
3.  Add one limitation.
```
